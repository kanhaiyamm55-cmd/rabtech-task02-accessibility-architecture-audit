# Evidence folder

Place genuine screenshots and exported reports here. Suggested filenames:

- `lighthouse-accessibility-overview.png`
- `lighthouse-accessibility-details.png`
- `keyboard-focus-first-control.png`
- `keyboard-focus-problem-control.png`

Each image should show enough context to identify the page and observed behavior. Do not add fabricated or unrelated screenshots. Remove personal data before committing evidence.
